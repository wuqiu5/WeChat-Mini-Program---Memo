# 蛋黄备忘录

> 一款轻量级的微信小程序待办事项管理工具，界面简洁清新，支持时间区间设置、提醒开关、本地数据持久化等功能。

## 项目简介

蛋黄备忘录是一个基于微信小程序原生框架开发的单机版 Todo 应用。整体配色以淡黄色为主色调，搭配蓝色操作按钮，营造出温暖而不失清爽的视觉体验。应用支持添加、编辑、删除、完成状态切换、时间区间设置与提醒开关等核心功能，并通过微信本地缓存机制实现数据持久化，无需后端服务即可使用。

## 功能特性

### 待办管理
- **添加事项**：输入待办内容，并设置开始时间和结束时间
- **编辑事项**：点击事项文本即可进入编辑模式，修改内容、时间和提醒状态
- **删除事项**：单条删除或一键全部删除
- **完成切换**：点击事项后的对勾图标切换完成状态，已完成事项样式区分显示

### 时间与提醒
- **时间区间**：每条事项支持设置开始时间与结束时间
- **提醒开关**：可为每条事项单独设置是否需要提醒
- **按时间排序**：事项列表按开始时间自动升序排列

### 列表筛选
- 显示全部事项
- 仅显示未完成事项

### 数据持久化
- 使用 `wx.setStorage` / `wx.getStorage` 将数据存储于本地缓存
- 提供"保存数据"按钮手动保存
- 退出后再进入应用可恢复上次保存的状态

## 页面结构

应用包含两个页面：

| 页面路径 | 功能说明 |
| --- | --- |
| `pages/index/index` | 主页面，提供事项的输入、列表展示与所有操作 |
| `pages/logs/logs` | 日志页面，展示本地缓存中的数据 |

## 开发环境

- **平台**：微信小程序
- **基础库版本**：2.25.3 / 3.6.5
- **AppID**：`wx3ece773c0b4aef7c`
- **开发工具**：微信开发者工具
- **导航栏背景色**：`#ff9d00`（蛋黄主题色）
- **导航栏标题**：蛋黄备忘录

## 快速开始

### 1. 克隆仓库

```bash
git clone <your-repo-url>
```

### 2. 导入项目

1. 打开**微信开发者工具**
2. 选择「导入项目」
3. 项目目录选择本仓库下的 `备忘录/` 文件夹
4. 填入自己的 AppID（或使用测试号）
5. 点击导入即可预览运行

> 如需使用项目自带的 AppID `wx3ece773c0b4aef7c`，请确认你已具备该 AppID 的开发权限，否则请替换为你自己的 AppID。

### 3. 预览与调试

- 在微信开发者工具中即可看到模拟器预览
- 点击「预览」生成二维码可用手机扫码体验
- 点击「真机调试」可在手机上进行断点调试

## 使用说明

1. 在顶部输入框中输入待办内容
2. 选择开始时间和结束时间，按需开启提醒开关
3. 点击「提交」按钮，事项将加入下方列表并按开始时间排序
4. 列表中：
   - 点击事项文本进入编辑模式，可修改内容与时间
   - 点击 ✓ 图标切换完成状态
   - 点击 ✕ 图标删除该事项
5. 底部操作栏提供：
   - **显示全部 / 显示未完成**：切换列表显示范围
   - **全部完成**：将所有事项标记为已完成
   - **全删**：清空所有事项
6. 点击「保存数据」按钮可将当前列表写入本地缓存，下次打开应用时自动恢复

## 技术说明

- 数据存储采用微信小程序原生 `wx.getStorage` / `wx.setStorage` API，基于 key 为 `todolist` 的本地缓存
- 时间排序通过自定义 `sortTasksByStartTime` 方法实现，按开始时间升序
- 时间选择使用小程序原生 `<picker mode="time">` 组件
- 用户登录与信息获取通过 `wx.login` 与 `wx.getUserInfo` 实现
